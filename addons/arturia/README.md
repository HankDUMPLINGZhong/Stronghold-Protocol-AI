# AI·阿尔图罗 v0.3.0

固定选择潘格尼尼／拉特兰，使用对应干员精二头像。本地规则＋战斗预演，无需LLM或API Key。

## 安装与升级

关闭游戏服务，解压ZIP，将插件文件夹放到游戏根目录或便携版启动脚本旁，双击**安装插件.bat**。重启服务并刷新浏览器，在等待室选择“添加精英干员 → 阿尔图罗”。菜单最多显示两项，其余滚动。

直接升级会保留其他插件；三款可按任意顺序安装，公共计算模块自动安装并复用兼容版本，不降级。

恢复记录在`.ai-addons/install.json`，请保留；更新游戏前先卸载插件。支持已验证原上游及扩展分支；v0.3.3仅开放默认第二期下半。普通AI继续使用宿主原策略。

## 策略与成绩

更新多人副阵容选择、持有重复干员的利用及安全与发育权衡；二人、四人分别采用最新基线。沿用安全公共计算层及阵容计算时间优化。
