# AI·祖玛玛 v0.2.0

固定优先选择佩佩／萨尔贡，使用森蚺精二头像。本地规则与战斗预演，无需LLM或API Key。

## 安装与升级

关闭游戏服务，解压ZIP，双击**安装插件.bat**并选择游戏目录。重启服务、刷新网页，在等待室选择“添加精英干员 → 祖玛玛”。菜单最多显示两项，其余滚动。

可直接升级并保留其他插件，三款无需指定安装顺序。公共计算API 1／1.1.0复用兼容版本，不降级。保留`.ai-addons/install.json`恢复记录；更新游戏前先卸载插件。支持已验证的原上游及扩展分支；v0.3.3仅开放默认第二期下半。

命令行：`node .\install.mjs install "游戏目录"`；检查与卸载分别将install改为check、uninstall。
