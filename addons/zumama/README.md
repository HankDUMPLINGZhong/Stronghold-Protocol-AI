# AI·祖玛玛 v0.1.2

固定选择佩佩／萨尔贡，使用对应干员精二头像。本地规则＋战斗预演，无需LLM或API Key。

## 安装与升级

关闭游戏服务，解压ZIP，将插件文件夹放到游戏根目录或便携版启动脚本旁，双击**安装插件.bat**。重启服务并刷新浏览器，在等待室选择“添加精英干员 → 祖玛玛”。菜单最多显示两项，其余滚动。

直接升级会保留已安装的其他插件；公共计算模块自动安装并复用兼容版本，不降级。拉维妮娅v0.2.1保持原版；若全新安装三款，先装拉维妮娅，再装新版图图／祖玛玛。已经安装新版后补装旧包，请使用游戏目录下新版入口：

`node .\addons\zumama\install.mjs install . "旧包解压目录"`

恢复记录在`.ai-addons/install.json`，请保留；更新游戏前先卸载插件。支持已验证原上游及扩展分支；v0.3.3仅开放默认第二期下半。普通AI继续使用宿主原策略。
