# AI·祖玛玛 v0.1.0

森蚺／祖玛玛作为具名 AI 队友，固定优先选择佩佩，采用萨尔贡最新已采用基线。本地规则与战斗预演，不调用 LLM，无需 API Key。

## 安装

关闭游戏服务，解压 `AI-Zumama-v0.1.0.zip`，将文件夹放在游戏根目录或便携版启动脚本旁，双击 **安装插件.bat**。重启并刷新浏览器，在“添加精英干员”中选择祖玛玛；菜单最多显示两项，其余滚动。头像使用游戏已有的森蚺精二资源 `char_416_zumama`，不附带游戏美术。

每房间最多一位祖玛玛，支持险境、绝境、终极。只需房主安装。原上游与扩展分支的已验证提交见仓库 `compatibility.json`。

## 共存与升级

新版共用安装管理器自动接入已安装的图图／拉维妮娅，保留其策略源码、运行适配器和版本；三位使用同一菜单，各自固定选择自己的策略。图图第一、拉维妮娅第二、祖玛玛第三；扩展分支按卡池组分别排优先顺序。普通 AI 保持原样。

共存后，原来的 `addons/<名字>/安装插件.bat` 仍可独立检查、升级或卸载该 AI；安装器统一管理共同入口，移除一个插件会保留其余插件。最终移除全部插件时恢复宿主原文件。保留 `.ai-addons/install.json`，安装中断时用同一安装器重试。更新游戏前先卸载，更新完成后重新安装。

## 策略与测评

单人绝境采用 `solo-c-combined`，终极采用预算＋LP换层；多人分别采用二人联动布阵和四人置信门槛＋迅捷保护 B，不按种子分流。仅影响显式加入的祖玛玛，游戏规则、经济、掉落和合法操作由宿主负责。

最新已采用固定诊断集：单人绝境 **28/28**、终极 **15/28**；多人终极二人 **18/56**、四人 **13/56**。新的共用计算执行已完整重放168局，与已采用轨迹逐字段一致，详细指标及验证边界见仓库策略文档。固定集成绩不代表自然随机开局胜率，也不代表扩展分支胜率。

共用计算模块独立记录 API、版本及哈希，策略保留候选、种子、预算和评分。需要逐步观察回调的预演仍在本地执行；安装共用线程池不等于所有萨尔贡预演都已并行。
