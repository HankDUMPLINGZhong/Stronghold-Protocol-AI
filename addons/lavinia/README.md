# AI·拉维妮娅 v0.1.2

斥罪／拉维妮娅作为具名AI队友，固定选择贾维并执行叙拉古策略。本地规则与战斗预演，不调用LLM，不需要API Key。

## 安装

关闭游戏服务，解压 `AI-Lavinia-v0.1.2.zip`，将插件文件夹放在游戏目录或便携版启动脚本旁，双击 **安装插件.bat**。也可在任意位置解压后运行安装器、选择游戏目录。需要Node.js22+，优先使用游戏自带Node。

重启游戏并刷新浏览器，在等待室选择 **添加精英干员 → 拉维妮娅**。只需房主安装，每房间最多一位。支持游戏0.2.4、0.3.0、0.3.1（b3deebda）与2026-10-19的master快照（c9d804f4），仅限险境、绝境、终极的原版玩法及纯外观插件。新版在0.3.1通过26项安装、共存、真实战斗至R14、升级和卸载检查，其他宿主由发行CI及隔离回归验证；完整记录见仓库`compatibility.json`。这是源码扩展包，不能通过插件工作台导入。

头像直接引用玩家游戏已有的斥罪精二资源 `char_4065_judge` 的 `avatarE2`，不附带游戏美术。[精二立绘来源核对](https://prts.wiki/w/文件:立绘_斥罪_2.png)。

## 与阿尔图罗同装

先安装阿尔图罗，再安装拉维妮娅。她们使用独立策略目录和适配器，共用“添加精英干员”菜单。

- 只有拉维妮娅在场：她第一选，只选贾维／叙拉古。
- 两人在场：阿尔图罗第一选潘格尼尼／拉特兰，拉维妮娅第二选贾维／叙拉古。
- “AI最后选择”开启时仍保留这两个优先位置；其他玩家的相对顺序保持原样。
- 各自开局为本人预约；普通AI和真人改名不会取得专属策略。

卸载或升级阿尔图罗前，先卸载后安装的拉维妮娅，再操作阿尔图罗。拉维妮娅卸载会恢复安装时的阿尔图罗接入文件。安装后手工修改过的文件会拒绝覆盖。

```powershell
node .\install.mjs check 'D:\Games\Stronghold-Protocol'
node .\install.mjs install 'D:\Games\Stronghold-Protocol'
node .\install.mjs uninstall 'D:\Games\Stronghold-Protocol'
```

安装器自动创建 `addons/lavinia`，完整安装后下载解压文件夹可删除。保留游戏中的 `.lavinia-addon/install.json` 恢复记录。安装器不会自动停止运行的服务。

升级v0.1.0或v0.1.1时，先关闭后台游戏服务，直接运行新版安装器即可；失败会恢复旧版本。只刷新网页不能让后台加载新策略。

## 策略与成绩

固定单人集 `enemy-diversity-v1`：绝境 **28/28**、终极 **12/28**；补充51001–51008两档为 **8/8、3/8**。胜场指R14领袖过关，不等于隐藏Boss全清，也不代表多人房胜率。

采用六种叙拉古优先的硬性选阵、路线相关叠层外援、每回合花光资金、七图阿罗玛固定点及决战最终朝向参与选位。晚升六需拟上场叙拉古和关键五阶全部精锐；单人卢西恩R14另有右侧集火站位，多人／联防仍使用通用决战布局。装备仅主动取得两种娃娃、叙拉古正装、同盟约招募电话机。小体型铳／卢西恩发展奥术突袭，仍叠迅捷。

策略和游戏规则分开：本包保留原版AI、宿主经济、数据、射程、合法行动和战斗引擎。固定开局只作用于显式加入的拉维妮娅。每次准备的预演上限3，实际候选去重后可能更少。
