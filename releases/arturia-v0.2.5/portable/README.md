# AI·阿尔图罗 v0.2.5

固定选择潘格尼尼／拉特兰，使用对应干员精二头像。本地规则与战斗预演，无需 LLM 或 API Key。

## 安装与升级

关闭游戏服务，解压 ZIP，将插件文件夹放到游戏根目录或便携版启动脚本旁，双击 **安装插件.bat**。重启服务并刷新浏览器，在等待室选择“添加精英干员 → 阿尔图罗”。精英菜单最多显示两项，其余滚动。

本补丁适配原上游 v0.3.3 默认「第二期下半」的 AI 准备接口、策略分发和新等待室，仍支持已验证的旧上游及扩展分支。精英保留自己的策略；普通 AI 保留宿主选择的 AI 实现。

三个新版插件均使用共用安装管理器，可任意顺序安装、独立升级或卸载，并自动接入已有旧版安装记录。升级一款会保留其他款。恢复记录位于 `.ai-addons/install.json`，请勿删除；更新游戏前先卸载插件。

三位精英同时在场时，选策略顺序为图图、拉维妮娅、祖玛玛，其后玩家保留原相对顺序；扩展分支按卡池组分别处理。每款每房间最多一位。

## 策略基线

本次仅修复宿主兼容与安装，不改变已采用策略。单人绝境 **28/28**、终极 **20/28**。

| 多人模式（终极） | 胜场/总场数 | 平均到达回合 | 图图拉特兰平均层数 | 图图平均漏怪 | 图图平均兜怪 |
|---|---:|---:|---:|---:|---:|
| 二人：图图＋bot | 22/56 | 12.63 | 186.39 | 28.04 | 25.46 |
| 四人：图图＋3bot | 18/56 | 13.07 | 193.91 | 26.50 | 56.71 |

以上沿用 v0.2.4 的原开发引擎固定诊断集，不是 v0.3.3 重测胜率。多人个人指标按全部对局平均，含提前淘汰；到达回合取队伍最高进入回合（含失败当轮）。

图图、拉维妮娅继续使用原冻结计算实现；祖玛玛沿用共用计算运行时 API 1／1.0.0，含回调的预演仍在本地执行。所有战斗规则和伤害结算均由宿主负责。
