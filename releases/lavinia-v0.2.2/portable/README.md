# AI·拉维妮娅 v0.2.2

固定优先选择贾维／叙拉古，使用斥罪精二头像。本地规则与战斗预演，无需LLM或API Key。

## 安装与升级

关闭游戏服务，解压ZIP，双击**安装插件.bat**并选择游戏目录。重启服务、刷新网页，在等待室选择“添加精英干员 → 拉维妮娅”。菜单最多显示两项，其余滚动。

可直接升级并保留图图、祖玛玛；公共计算API 1／1.1.0复用兼容版本，不降级。请保留`.ai-addons/install.json`恢复记录。支持已验证的原上游和扩展分支；v0.3.3仅开放默认第二期下半。更新游戏前先卸载插件。

命令行：`node .\install.mjs install "游戏目录"`；核验和卸载分别将install改为check、uninstall。
