# 共用计算模块

祖玛玛 v0.1.0 首次在本发行仓库使用共用计算 API 1／运行时 1.0.0。原始工程来自 2026-10-26 已验证的开发抽取，包含隔离预演、顺序任务、命名空间缓存、宿主身份、生命周期和共用线程池八个模块，逐文件哈希登记在发行清单。

策略继续决定候选、种子、预算、评分和取舍；底层只执行请求，不改变购买、合法操作或战斗规则。203 份萨尔贡策略依赖保持独立冻结，22 份模块仅把创建和步进预演的调用接到宿主公共路径；原始源码和执行接入后的哈希分别保留。

本次已完整重放单人 56 局、多人 112 局，与最新已采用记录逐字段一致，成绩保持28/15与18/13；全部56局同开局原版单人对照为2/28、0/28。游戏引擎及原策略评分不因此更新。[发行验证记录](../benchmarks/zumama-v0.1.0-validation.json)保存各模式摘要、输入及输出哈希。

线程池可供可序列化的独立样本调用；含逐步回调的现有萨尔贡预演仍在本地执行。使用共用底层不表示这些预演已自动并行，也不把其他策略的加速比例作为祖玛玛的实测成绩。

共用计算只安装一份。图图 v0.2.4 和拉维妮娅 v0.2.0 接入统一安装管理器时，继续使用原冻结策略和适配器，其计算实现不会被偷偷切换。三款使用同一登记和等待室菜单，但策略对象与状态相互隔离。
