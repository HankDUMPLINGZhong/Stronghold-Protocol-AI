# 拉特兰策略 · 阿尔图罗

阿尔图罗v0.2.3优先选择潘格尼尼。单人冻结`team28-vision-difficulty`；多人冻结`coop-sixteen-team-lp-only`，加入坦奶补位、保守发育、远见买卖和补强估值，以自身Boss伤害评估决战候选，队友信息收敛为存活与LP。复用预演样本并提前停止无望候选，优化计算时间。二人／四人共用配方、分别回归。
