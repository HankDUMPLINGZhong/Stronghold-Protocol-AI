# 发行源码结构

- `addons/arturia/`：阿尔图罗适配器、安装／卸载入口和可安装策略文件。
- `releases/arturia-v0.1.0/source/`：该发行包必需的固定源码依赖闭包；不是独立发布其他策略。
- `catalog.json`：已发布策略、版本、构建源码位置与清单。
- `benchmarks/`：固定场景与已发布策略的原版同开局对照。

策略使用本地规则和有预算的战斗预演，动作仍由宿主游戏校验。原版AI保留，具名队友的固定开局由适配器声明。

未来新增策略先在原项目`dev`完成开发验证，确认发布后再加入此仓库。已发布版本保持不可变。参与方式见[贡献说明](../../CONTRIBUTING.md)。
