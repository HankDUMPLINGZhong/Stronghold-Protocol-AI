# 固定测试集

测试集名称`enemy-diversity-v1`。先从20001–30000共10000个种子预生成敌人环境，再按7类关底Boss、7张地图、中间敌人种类及组合覆盖选出28个固定场景。选种不读取AI胜负。

- 绝境、终极各28局，单人，真实战斗，关闭随机盟约禁用。
- 每种Boss和地图各4场；飞行、频次、元素、持续、隐匿、折射六类各14场，覆盖20种三类别组合。
- 公开阿尔图罗及原版同开局对照，两套配置共112局。
- 过关指击败R14领袖，不等同于隐藏Boss全清；提前淘汰也计入分母。
- 平均存活回合统计全部28局已通过回合；R13核心层数只统计到达检查点的局，并显示样本数。

这是均衡诊断集，不代表自然随机开局分布或多人房胜率，也不是未见留出集。
