# 拉维妮娅／叙拉古

AI拉维妮娅v0.1.0固定优先选择贾维，以六种叙拉古及持续叠层为主线；仅核心人数或层数高不足以保证胜利。

- R1优先叙拉古并取得两名防守干员；R2升二本，开局缺前排时R3补位。每回合花完资金后才锁定关键商店。
- 外援围绕路线相关的突袭、奥术、迅捷叠层及三个不同投资人选择；铳／卢西恩采用奥术突袭路线，并保留迅捷与备用奥术。
- 仅主动取得两类娃娃、叙拉古正装和同盟约招募电话机；不增加提前升本因子。
- R1–13阿罗玛按地图固定位置和朝向；决战先满足可实现的六叙，再按最终朝向布阵与预演。突袭朝右，激活时尝试空场起点和合法落点。

固定单人诊断集：绝境27/28、终极11/28；相同贾维开局原版3/28、0/28。完整开发矩阵448局验证，叙拉古56局逐条复现、其余392局不变；补充16局8/8、2/8。成绩指击败R14领袖，不代表隐藏Boss全清或多人房胜率。

上述为AI决策启发式 `[ASSUMED]`，不修改游戏效果、合法操作、卡池或发牌概率。本地规则＋最多三套战斗预演，无LLM或API Key。源码、逐文件哈希和配置见[发行清单](../../releases/lavinia-v0.1.0.json)、[测评配置](../../benchmarks/policies.json)和[逐局结果](../../benchmarks/results.json)。
