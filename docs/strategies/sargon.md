# 萨尔贡策略 · 祖玛玛

AI·祖玛玛（森蚺）v0.1.0 固定优先选择佩佩，使用森蚺精二头像。策略以萨尔贡叠层、精锐化、精准火力与适量迅捷支线为主，所有买卖、升本、装备和部署仍走宿主合法操作。

- 单人绝境保留 `solo-c-combined`，终极采用预算＋LP 换层；不按种子调整配方。
- 二人使用已采用的动态坚守与联动布阵，四人使用独立库存空间、置信门槛与防守收尾迅捷保护 B。
- 多人准备在普通 bot 队友之后读取其实际棋盘，真人不会因此被要求先准备。
- 新共用计算执行保持原候选、预算和评分，含观察回调的预演保留本地路径。

单人绝境 **28/28**、终极 **15/28**；同佩佩开局原版单人对照 **2/28、0/28**。多人终极二人 **18/56**、四人 **13/56**。完整个人层数、漏怪和兜怪表由[多人数据](../../benchmarks/zumama-v0.1.0-multiplayer.md)提供；单人见[逐局结果](../../benchmarks/zumama-v0.1.0-solo.json)。
