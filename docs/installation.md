# 安装、共存和升级

下载对应 ZIP，关闭游戏服务，把解压的插件目录放到游戏根目录或便携版启动脚本旁，双击“安装插件.bat”。安装后重启服务并刷新网页。仅房主需要安装。

## 祖玛玛及共用安装管理器

祖玛玛 v0.1.0 使用共用管理器。首次安装会校验已存在的图图／拉维妮娅安装记录，保留其原策略文件、运行适配器和版本，再统一生成协议、等待室菜单及分发入口。该过程不把图图或拉维妮娅改成其他策略，也不替换其历史发行附件。

策略数据分别位于原独立目录或 `server/match/aiAddons/<名字>/`；计算模块仅有一份 `server/match/aiCompute/`。每款插件仍有 `addons/<名字>/` 下的双击入口。旧恢复记录转换为 `.ai-addons/install.json` 后，共同入口及事务恢复由统一管理器负责。

升级或卸载一款插件会保留其他款。新版管理器接入后，旧插件已有双击入口也会转交统一管理器；即使先卸载祖玛玛，图图与拉维妮娅仍能继续运行并独立管理。移除最后一款时恢复宿主原文件字节。

安装器先完成全部路径、文件及底层兼容校验，再提交事务。已有文件被手改、版本降级、同版本不同内容或不兼容底层会拒绝安装。失败时回滚；意外中断时保留事务记录，用同一个安装器重试恢复。不要手工删除恢复记录。

## 旧独立发行包

仅安装图图／拉维妮娅而尚未安装祖玛玛时，沿用其原说明：图图先装、拉维妮娅后装，图图 v0.2.2 起升级会自动保留拉维妮娅，卸载图图前先卸载拉维妮娅。祖玛玛安装后改由统一管理器处理，三款可独立移除。

## 宿主与固定开局

原上游和扩展宿主均按结构校验，验证的版本与提交见[兼容记录](../compatibility.json)。扩展宿主使用组内优先顺序、组内策略保留和对应卡池，其他组仍可选择相同策略。游戏规则及禁用表由宿主决定。

精英顺序为图图、拉维妮娅、祖玛玛，其后玩家保留原相对顺序。每位精英只选自己的固定开局；普通 AI 不使用精英策略。

## 排查

先确认运行服务的目录就是安装目录，再完全重启服务。看到精英名称及正确开局说明对应入口已加载；若操作表现有疑问，提供插件版本、宿主提交、难度、种子和具体回合，不仅凭胜负判断是否回退为原版 AI。
