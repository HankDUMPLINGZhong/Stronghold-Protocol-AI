# 安装、共存和升级

关闭游戏服务，解压对应 ZIP，把插件文件夹放到游戏根目录或便携版启动脚本旁，双击“安装插件.bat”。完成后重启服务并刷新浏览器。仅房主需要安装。

## 当前补丁版本

图图 v0.2.6、拉维妮娅 v0.2.1、祖玛玛 v0.1.2 均使用共用管理器。新版之间新版之间新版之间新版之间可任意顺序安装，升级或卸载一款会保留其他款；原有旧版安装记录可自动接入。每款仍有 `addons/<名字>/` 下的双击入口。

安装记录位于 `.ai-addons/install.json`。安装器先校验全部路径与文件，再提交事务；失败时回滚，意外中断时用同一安装器重试恢复。手改文件、版本降级、同版本不同内容或不兼容底层会拒绝覆盖。不要删除恢复记录强行安装。移除最后一款时恢复宿主原文件字节。

更新游戏前先卸载插件，更新完成后重新安装。只升级插件时直接使用新版安装器，无需先卸载其他 AI。

## 宿主与策略

本次专门适配原上游 v0.3.3 的默认「第二期下半」，其他官方规则版本不开放精英入口，并保留既有上游与扩展分支支持，精确提交见[兼容记录](../compatibility.json)。图图、祖玛玛更新至2026-10-27已确认基线，拉维妮娅保持原基线；v0.3.3 实战测试验证接口可运行，不作为新上游胜率报告。

精英选策略顺序为图图、拉维妮娅、祖玛玛，其后玩家保留原相对顺序；各自策略预留给对应精英。扩展分支在各卡池组内分别处理，其他组仍可选择同一策略。普通 AI 保留宿主原有或明确选定的实现。

图图、祖玛玛接入共用安全计算API 1／1.1.0，拉维妮娅v0.2.1保持。伤害预估调用宿主公开结算接口，不替换游戏规则或结算代码。

## 历史独立包

仅使用图图 v0.2.4、拉维妮娅 v0.2.0 及更早独立包、且未安装祖玛玛时，仍按原说明：图图先装，拉维妮娅后装，卸载图图前先卸载拉维妮娅。这些历史包不能用于 v0.3.3，请下载当前补丁版。已有祖玛玛 v0.1.0 共用记录也可直接升级。历史源码、附件及标签保持不变。

## 排查

确认运行服务的目录就是安装目录，再完全重启服务。仅关闭网页或重建房间不能重载 Node 模块。出现锚点不匹配时不要手工删除校验：提供插件版本、宿主版本／提交和完整报错，以便验证接口。

## 补装旧版拉维妮娅

旧发行包保持不可变，其自带旧管理器无法合并新版公共模块。全新安装三款时可先装拉维妮娅；已有新版图图／祖玛玛时，在游戏目录使用新版入口补装旧包，无需卸载：

```powershell
node .\addons\arturia\install.mjs install . "D:\Downloads\AI-Lavinia-v0.2.1"
```

也可使用祖玛玛新版入口。此操作保留旧包自身版本、源码与哈希，公共模块和管理器取兼容较新版本。
