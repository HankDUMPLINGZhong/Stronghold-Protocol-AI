安装器检查分组轮选代码和等待室结构，不依赖目录名、Git remote 或仍为 0.3.1 的基础版本号。原上游继续执行原安装路径，生成的接入补丁保持一致。识别到已知扩展结构时才采用专门步骤；缺失或重复接入点会在写文件之前拒绝安装。

扩展步骤适配等待室精英入口和头像、组内图图／拉维妮娅优先顺序、组内策略保留，以及各组独立的棋子／装备池。其他分组可以正常选择同一策略。图图和拉维妮娅仍各限每房间一位；普通 AI 和分组规则由宿主处理。

休整期回档不保存带函数的衍生策略缓存，恢复后重新计算缓存；重启恢复对局时从已保存的房间座位补回精英身份。实际棋盘、经济、层数与 AI 决策状态继续由宿主保存。两款单独安装、共存安装及升级均使用相同的识别流程，卸载按记录恢复原始文件。
